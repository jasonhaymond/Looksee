# Looksee 5.0 — plan and status

**Status: in progress.** Nothing here is released yet; each item's status is kept current
as it's built. One release (5.0.0) at the end, through the security gate.

Requested 2026-10-19 (20 items). Decisions made with Jason the same day:

| Decision | Choice |
|---|---|
| Hierarchy | **Location → Site → Endpoint → Check.** Today's "endpoint" (a network) becomes a **Site**; today's "host" (a device) becomes an **Endpoint**. Agent optional on any endpoint; any endpoint can be its site's collector. Groups cut across all levels. |
| Rename depth | **Everything, including the database** (tables, columns, enum values, JSON keys). Rolling back to 4.x after this needs the pre-update database snapshot. Check-type IDs (`host_cpu`, `host_change`, …) stay as stable identifiers; only their labels change. Agent wire protocol stays compatible with 4.x agents. |
| Watchdog agents | Per agent: email (agent receives SMTP settings) and/or a chat/webhook channel. |
| Linux agent privileges | Privileged systemd drop-in by default (service user, not root). |
| Exclusions | All three: ignore items inside a check; exclude results from stats; reusable global exclusion lists. |
| Recovery by event | All three: matching "clear" trap/syslog; another check recovering; an explicit "up" heartbeat/push. |
| Releases | One release, 5.0.0. |

Related: [README](../../README.md), [spec.md](../../spec.md), [CHANGELOG](../../CHANGELOG.md).
